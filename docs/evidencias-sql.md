## Decisão D01 — Indisponibilidade de Equipamentos Aguardando Calibração

- **Status / Situação:** Definida e Implementada.
- **Regra de Negócio:** Equipamentos cadastrados com situação operacional de manutenção, baixados ou com status/estado pendente de "aguardando calibração" **não são considerados disponíveis** e ficam automaticamente bloqueados para novas alocações no período solicitado.
- **Justificativa Técnica:** A precisão das medições ambientais e a segurança das expedições subterrâneas dependem estritamente do pleno funcionamento e calibração prévia dos instrumentos. Permitir a reserva de equipamentos pendentes de calibração compromete a validade científica das amostras e viola os protocolos de segurança do projeto TurmalinaPB.
- **Implementação no Código:** Refletido na consulta nomeada `Equipamento.listarDisponiveisNoPeriodo` no `orm.xml`, que filtra os equipamentos operacionais e utiliza a cláusula `NOT EXISTS` para verificar a ausência de movimentações conflitantes diretamente no banco de dados.
